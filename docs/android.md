# RVPN Android Client

Android 10+ (API 29+) VPN client for the RVPN protocol.

## Architecture

┌────────────────────────────────────────────────────────┐
│ Android UI (MainActivity) │
│ - Connect/Disconnect toggle │
│ - Server, pinned-key or certificate credentials, tunnel IP, DNS │
│ - Requests VPN permission via VpnService.prepare() │
└───────────────────────────┬────────────────────────────┘
│
┌───────────────────────────▼────────────────────────────┐
│ RvpnService (Android VpnService) │
│ - Builds virtual L3 TUN interface │
│ - Calls protect(socketFd) to prevent routing loops │
│ - Passes detached TUN fd to native Rust runtime │
└───────────────────────────┬────────────────────────────┘
│ JNI (RvpnNative)
┌───────────────────────────▼────────────────────────────┐
│ Rust Native Core (librvpn_android.so) │
│ - Wraps TUN fd via VirtualInterface::from_raw_fd() │
│ - Runs Tokio event loop (handshake, seal/open, rekey) │
│ - Handles graceful shutdown via watch channel │
└────────────────────────────────────────────────────────┘

## Prerequisites

**Rust toolchain** with Android targets:

```bash
   rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
```

**Android NDK** (r25+ recommended) and `cargo-ndk`:

```bash
   cargo install cargo-ndk
```

**Android Studio** or Android SDK command-line tools.

## Building the Native Library

From the workspace root or `apps/rvpn-android`:

```bash
# Build 64-bit ARM (standard for modern Android phones)
cargo ndk -t arm64-v8a -o apps/rvpn-android/android/app/src/main/jniLibs build --package rvpn-android --release

# Build x86_64 (for Android emulator)
cargo ndk -t x86_64 -o apps/rvpn-android/android/app/src/main/jniLibs build --package rvpn-android --release

# Build 32-bit ARM (optional for older devices)
cargo ndk -t armeabi-v7a -o apps/rvpn-android/android/app/src/main/jniLibs build --package rvpn-android --release
```

## Running the Android App

1. Open `apps/rvpn-android/android` in Android Studio.
2. Ensure the native libraries are placed in `app/src/main/jniLibs/<abi>/librvpn_android.so`.
3. Build and deploy to an Android 10+ device or emulator:

```bash
   ./gradlew assembleDebug
   adb install app/build/outputs/apk/debug/app-debug.apk
```

4. Open the **Config** tab and provide the client configuration one of two ways:
   - **Scan a QR code** generated by `scripts/generate_rvpn_setup.py`, which
     writes a `client-<peer>.toml` per Android peer and (with `segno`
     installed) a matching QR PNG containing that peer's compacted
     `client.toml`.
   - **Paste a `client.toml`** directly (WireGuard-import style) — either
     typed/copied in, or pulled from the clipboard via **Paste from
     clipboard**.

   Either path is parsed by the app's TOML config parser and saved to
   app-private storage; the app does not require manual credential entry.
   The top-level `dns_replace` setting is optional and defaults to `false`.
   When enabled, Android saves the resolved server IP into the imported config
   after resolving the hostname.
5. Switch to the **Main** tab and tap **Connect**. The app requests VPN
   permission via `VpnService.prepare()` the first time, then starts the
   foreground tunnel service.

## Configuration and supported features

The Android app supports protocol v3 pinned-key and certificate
authentication. The setup builder can generate an Android client TOML file
and optional QR image for either mode. Certificate clients need the peer
identity seed, signed client certificate, and CA public key from that file.

Android uses TUN mode. Imported configuration can set IPv4 and IPv6 tunnel
addresses, DNS servers, default or split routes, MTU, obfuscation, handshake
retry settings, rekey packet limit, and whether a resolved endpoint replaces
its hostname in the saved config. The form also supports excluding selected
Android applications from the VPN. TAP mode and server-only settings such as
forwarding, peer links, DNS upstreams, and usage history are configured on the
server, not on the Android device.
